# Motores de Videojuegos I — Primera clase

Bienvenido. En esta actividad construirás una escena 2D con un personaje, un piso, un obstáculo, una señal de entrada y una salida. Usarás cuadrados como recursos provisionales.

## Obtener el proyecto con Git

Clona el repositorio de distribución y conecta tu repositorio individual siguiendo la guía de Git. El remoto curso recibe las actividades y origin guarda tu trabajo. [Preparación y actualizaciones](GUIA_GIT.md).

## Abrir el proyecto en Windows

1. Abre Unity Hub y selecciona Add o Agregar proyecto desde disco.
2. Selecciona la carpeta ProyectoUnity dentro de tu clon. Dentro de ella encontrarás Assets, Packages y ProjectSettings.
3. Usa el Editor Unity 6000.3.10f1. En la primera apertura Unity descargará los paquetes del proyecto e importará los recursos. Se necesita conexión durante esta preparación.
4. En Project, abre Assets/Curso/U01/DEMO_Escena.unity con doble clic. En Game verás Jugador azul a la izquierda, Suelo gris y Meta verde a la derecha.
5. Sigue la guía de la clase. [Actividad U01 S01](clases/U01_S01.md).

Si recibiste una vista ZIP para revisión, extráela en una carpeta nueva y abre su ProyectoUnity con los mismos pasos.

## Dónde guardar tu trabajo

Crea la carpeta Alumno dentro de Assets y después U01 dentro de Alumno. Guarda tu copia como TramoBase_U01 mediante File > Save As… en Assets/Alumno/U01.

La carpeta Settings contiene configuración de renderizado y InputSystem_Actions es un recurso de soporte del proyecto. Trabaja con las piezas de DEMO y con tu copia de la escena durante esta clase.

Al terminar tendrás tu escena, sus archivos .meta y un registro breve de comprobaciones. El profesor indicará el canal de entrega. [Registro de la actividad](clases/Registro_U01_S01.md).
